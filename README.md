# 고누 온라인

우리 옛 말판 놀이 **고누** 7종(우물·호박·줄·참·네바퀴·네밭·오밭고누)을 브라우저에서 두는 웹 게임입니다.

- 혼자 두기(컴퓨터 쉬움·보통·어려움), 둘이서 한 화면, 온라인 초대(방 코드·초대 링크)
- 규칙 엔진 `games.js` 하나를 화면과 서버가 함께 씁니다. 서버가 모든 수를 다시 검사합니다.

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `games.js` | 고누 7종 규칙 엔진·컴퓨터 상대 (브라우저·서버 공용) |
| `ui.js` | 메인 화면, 대국 화면, 온라인 연결 |
| `api/room.js` | 온라인 방 API (Vercel Serverless Function) |

## 배포 (Vercel)
1. 이 저장소를 Vercel에 Import 합니다. 프레임워크는 **Other**, 빌드 설정은 비워 둡니다.
2. Vercel 프로젝트 → **Storage** → **Upstash for Redis**(Marketplace)를 만들어 이 프로젝트에 연결합니다.
   - 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경 변수가 자동으로 들어갑니다. (`UPSTASH_REDIS_REST_URL/TOKEN` 이름도 인식합니다.)
3. 다시 배포(Redeploy)하면 온라인 대전이 켜집니다. Redis가 없어도 혼자·둘이 모드는 동작합니다.

## 온라인 방식
- 방은 Redis에 7일 보관됩니다. 상대 차례일 때 0.8초, 내 차례일 때 3초마다 서버를 확인합니다(창이 안 보이면 6초).
- 같은 브라우저 탭은 새로고침해도 자리가 유지됩니다. 같은 기기에서 다시 접속하면 30초 이상 비어 있는 자기 자리를 되찾습니다.
